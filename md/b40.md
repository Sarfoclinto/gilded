# B40 - Practice update: company name under the logo (web only, no migration)

A deliberately tiny change so you can walk the whole update process once.

- `web/src/layouts/Sidebar.tsx`: the small line under "GILDED" in the side menu says "Gilded Gold Enterprise" instead of "Gold buying console".
- `CHANGELOG.md`: line for v1.0.2.
  No database change, no desktop installer needed (the desktop app shows the web screens it was built with, so desktop computers would see this only after a new installer; ignore that for the practice).

## Verified

Text change only; web type-check and tests are unaffected.

## Git steps (branch `chore-company-name-in-menu`), run on your laptop in the project folder

```
git checkout master && git pull
git checkout -b chore-company-name-in-menu
# copy the two delivered files into place, then:
git status
npm test
npm run typecheck
cd deploy && docker compose up -d --build && cd ..     # open http://localhost and look at the side menu
git add -A
git commit -m "Show the company name under the logo in the side menu"
git push -u origin chore-company-name-in-menu
```

On GitHub: **Compare & pull request**, wait for green checks, **Merge**. Then:

```
git checkout master && git pull
git tag v1.0.2 && git push --tags
```

Rehearsal (guide 09 step 4) is not required for a text change; do it once anyway for practice if you want. Install at night on the server:

```
ssh deploy@<server IP>
tmux new -s update
cd ~/gilded/deploy
git log --oneline -1        # write the code down (rollback point)
./scripts/update.sh
```

Check: `docker compose ps`, https://app.gildedgold.org/health/ready, reload the site (the menu line changed), `docker compose logs api --tail 50`.
Roll back (if ever): `git checkout <the code you wrote down>` then `docker compose up -d --build`.
