# B47 - Guide 11: releasing a desktop update

Documentation only; no code changed. New file `docs/deployment/11-desktop-releases.md`, read from the real updater code (`desktop/src/updater.ts`, `config.ts`, `Caddyfile`): computers read `/updates/win/<channel>/latest.yml`, the channel is chosen per computer by `%APPDATA%\Gilded\config.json`, and installers are Git-ignored so they reach the server only by scp.

## Two things worth knowing
1. **The desktop app carries its own copy of the screens.** B44, B45 and B46 changed screens, so desktop computers will not show them until a new installer is released (the server update alone only changed browsers and phones).
2. **Never build a separate "beta installer".** The channel is per computer, so the same installer is tested on beta and then copied unchanged to stable.
