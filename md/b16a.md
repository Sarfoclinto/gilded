# B16a — where the gold comes from (step 1 of "what carat to expect")

**What it does:** an optional "Gold from (town)" line on the New transaction page. It is a search box over the company's own list of towns. If the town is not there, "Add “xyz”" saves it for everyone. Matching ignores case, spaces and punctuation, so "obuasi " finds "Obuasi" instead of making a second one. It works offline: the list is kept on the device and a new town is created together with the purchase. The town is shown on the transaction page. Nothing is required, so skipping it costs no time.

**Not in this batch (next steps):** the "usually 22 high here" hint, the news feed, the "unusual for this town" flag, and a manager screen to rename or merge towns.
