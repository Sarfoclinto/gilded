# B44 - Switch off the note-by-note drawer rule for a branch (the amount is always enforced)

## What it does
Company settings > **Cash and allowance** > "Branches that do not enforce single notes" (directors; empty by default = nothing changes anywhere).
For a branch in that list:
- **Paying a customer:** every note is offered, no per-note limit. The teller sees "Enter the notes you hand out", prefilled with a suggestion, and the notes they enter **must add up exactly to the cash amount**. They cannot pay more than the drawer holds in total (red message, Save blocked).
- **Paying a waiting purchase (two-step), changing notes:** same rule; only the money has to be there.
- **Opening and closing the day:** notes are still counted and entered, and the books are corrected to the notes you counted. Only the **total** must match: a different mix of notes with the same total needs no written reason and no sign-off; the difference by note is kept on the day's record for the manager. A different total needs a reason exactly as before.
- Every other branch is unchanged.

## Decision to know about
The server has never refused a payout for lack of single notes (the screens and the branch hub do that; offline payouts are kept "reality wins"). I did not add a server refusal, because cash already handed over cannot be un-handed. So the money rule is enforced on the screens and the hub, and the books flag a negative drawer as before. If you want the server to also refuse online payouts above the drawer total, say so (next batch).
