# B41 - Hub tests no longer fail on Windows

## Cause
On Windows a file that is still open cannot be deleted. The hub tests (hub.test.ts, sim.test.ts) opened SQLite database files in a temporary folder and never closed them before the folder was removed, so cleanup failed with `EPERM, Permission denied` and 17 tests were marked failed. The hub itself was fine (the checks inside the tests passed); this was only a test-cleanup problem. It never showed on Linux, where deleting an open file is allowed.

## Changes (tests only, no app code)
- `desktop/src/hub/hub.test.ts`: every database the tests open is remembered and closed before the temporary folder is deleted.
- `desktop/src/hub/sim.test.ts`: closes the old database before each simulated hub restart, and closes the last one before cleanup.

## Verified
Desktop tests: 62 of 62 pass here (Linux). Please run `npm test` in `desktop` on your Windows laptop: that is the real check.
