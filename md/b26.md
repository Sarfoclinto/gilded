# B26 — Offline foundation, part 2: Director limit, bigger local store, clock check

## What changes for people
- **Settings → Working offline → "Days a device may work offline"** (Director; default 7, range 1–30). Each device remembers the last value it heard and applies it to the stored copy and to offline sign-in.
- **Company settings now survive a restart with no connection.** Before, an offline restart fell back to defaults (e.g. "pay at once" even when two-step payout is on). This was a real hole.
- **Recent transactions and debts can be opened offline** (they are kept on the device with the rest of the stored copy). The cache moved from localStorage to IndexedDB (much larger, no screen stalls). Same privacy rules as the customer list: 7 days (or the Director's number), cleared on company change and by "Forget this device".
- **Wrong-clock warning.** If the computer's clock differs from the server's by more than 5 minutes an amber notice appears at the top of every page ("about 3 days behind the server"). Purchases are stamped with the device clock.
- **Receipts waiting to be sent** now print "Pending · A1B2C3" (first 6 characters of the purchase id, same code as in the QR) instead of just "Pending", so paper can be matched to the record later.
