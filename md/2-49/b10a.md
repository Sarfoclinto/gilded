# B10a: transfer pages (frontend only)

No backend, database or API change. Nothing new to migrate. C# not touched.

## New files (copy into `web/src/`)

- `features/transfers/model.ts` and `model.test.ts`: on-the-road age, summary figures, search, difference on receipt
- `features/transfers/GoldPicker.tsx`: search, select all, running totals
- `shared/ui/Stepper.tsx`: Drafted / On the way / Received progress

## Changed files

- `features/transfers/AddItemsModal.tsx`: uses GoldPicker
- `features/transfers/pages/TransfersPage.tsx`: KPIs (click to filter), 3+ day warning, search, direction and status filters in the URL, table plus phone cards, pager
- `features/transfers/pages/NewTransferPage.tsx`: numbered steps, kind cards, gold picker, sticky summary bar
- `features/transfers/pages/TransferDetailPage.tsx`: route header, stepper, one main action (hand over at origin, receive at destination), carried by / sent / received cards with the difference, gold list, existing dialogs unchanged

## Behaviour notes

- "Hand to the collector" is now disabled until a collector is set (the warning already said so).
- The list reads up to 100 transfers and filters on the screen, so the headline figures stay whole.
