# B39 - Keep secrets, backups and installers out of Git

- `.gitignore`: ignores `.env`, `deploy/.env`, `deploy/backups/`, `*.sql.gz` and everything in `deploy/updates/win/*/` except `.gitkeep`. (`desktop/release` was already ignored. Before this, `git add -A` would have committed `deploy/.env` with the real passwords and the nightly backups with customer data.)
- The four scripts in `deploy/scripts/` are marked executable in Git (`git update-index --chmod=+x`), so a server pull or reset no longer removes the flag.
- `.gitattributes`: shell scripts always use Unix line endings (stops "bad interpreter" errors on the server).

## Check right now (important)
```
git log --all --oneline -- deploy/.env deploy/backups
```
If this prints anything, a secret or backup was committed and pushed. Tell me before doing anything else: the passwords in that `.env` must be changed on the server and the file removed from the history.

## Git steps (branch `chore-ignore-secrets-and-installers`)
```
git checkout master && git pull
git checkout -b chore-ignore-secrets-and-installers
git update-index --chmod=+x deploy/scripts/backup.sh deploy/scripts/first-company.sh deploy/scripts/restore.sh deploy/scripts/update.sh
git add -A
git status
git commit -m "Ignore secrets, backups and installers; make deploy scripts executable; master as branch name in guides"
git push -u origin chore-ignore-secrets-and-installers
```
Pull request, green checks, merge. No tag and no server install needed: nothing changes in the app.
