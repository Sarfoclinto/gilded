# B10b: open and close day screens (frontend only)

No backend, database or API change. Nothing to migrate.

## New files (copy into `web/src/features/drawer/`)
- `FigureBadge.tsx`: status label for a closing figure (Not entered / Matches / Short / Over / Different notes)

## Changed files (same folder)
- `NoteCountInput.tsx`: − and + buttons on every note row, row turns green/amber against the books (closing), Clear button, dark total bar. The optional typed total moved to the top and is clearer that it is only a check and is never saved.
- `closing.ts` and `closing.test.ts`: added `figureState` and `closingProgress` (pure, tested)
- `pages/OpenDayPage.tsx`: long date, books card with the amount and an "It is all there" button, clearer short/over wording
- `pages/CloseDayPage.tsx`: five numbered sections (Cash, Gold, Money, Held as security, Confirm), status badge on each figure, sticky bar with "N of 7 figures entered / N differ" and a progress line. The cash "short" warning no longer shows before anything is counted.

## Behaviour that did not change
All rules, payloads and server calls are the same. The close and open buttons enable under the same conditions as before.
