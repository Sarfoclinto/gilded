# B22 — Form no longer resets when the calculators open; new "Focus" design for a purchase

## The reset bug
On desktop, opening the calculator panel moved the whole page into a different place in the layout (it was wrapped in a Splitter only while the panel was open), so React rebuilt the page and a half-filled New transaction form lost everything. Fixed in `AppLayout.tsx`: the page now stays in the same place; the panel is added beside it, with a drag bar (and arrow keys) to resize. Checked in a browser: typed a name and weight, opened the calculators, both kept (before the fix both were empty).

## Focus design (second way to enter a purchase)
- A yellow **Input** card with big tiles (Top weight, Down weight, Price per pound) and a dark **Results** card (Pounds, Density, Karat used, Purity, and the amount to be paid in big type, with net weight). It edits the same items as Classic, so switching loses nothing. Everything else on the page (customer, town, payout, split, save) is the same in both.
- **Switch**: a sliding pill (Classic | Focus) at the top of New transaction, and also in My settings > New purchases. Kept per person on the device. Default stays Classic.
- **On-screen number pad** on touch screens (My settings: "Number pad on touch screens", on by default): 0-9, ".", "00", delete, Next (top, down, price, next item) and Done. The phone's own keyboard stays closed, so nothing covers the form; the pad shows the amount to be paid while you type the price. The first key pressed on a field that already has a value (e.g. today's price) replaces it, as on a calculator. On a computer you type with the keyboard as usual.
- Big boxes sit side by side with the results on very wide screens, stacked otherwise.
